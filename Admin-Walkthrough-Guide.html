1. How to Add Photos to the Gallery

  1. 1 Log in at /admin/login with your admin credentials.
  2. 2 In the left sidebar, click "Gallery".
  3. 3 You'll see the "Upload New Image" form at the top:
    • Click "Choose File" and select an image (JPG, PNG, or WEBP, max 5 MB).
    • Enter a Title (required) — e.g., "3-Tier Wedding Cake".
    • Optionally enter a Description — e.g., "White fondant with gold leaf accents".
  4. 4 Click the "Upload" button.
  5. 5 The image will appear in the grid below and will also be visible on the public Gallery page.
💡 Tip: Use high-quality images but keep them under 2 MB for best performance. Square images (1:1 ratio) look best in the gallery grid.

2. How to Remove Photos from the Gallery

  1. 1 Log in and navigate to "Gallery" in the admin sidebar.
  2. 2 Find the image you want to remove in the gallery grid.
  3. 3 Click the red "Delete" button under the image.
  4. 4 A confirmation dialog will appear — click "OK" to confirm.
  5. 5 The image is removed from both the admin and public gallery immediately.
⚠ Note: Deletion is permanent — the image file is removed from the server and cannot be recovered.

3. How to Edit Text on Web Pages

  1. 1 Log in and click "Edit Pages" in the admin sidebar.
  2. 2 You'll see sections for each page (Home, About, etc.).

Editing Hero Banners

Each page has a Hero Banner section at the top. You can edit:

  • Eyebrow Text — the small label above the heading (e.g., "Bespoke Bakery")
  • Heading — the main title (e.g., "We bake your cake")
  • Heading Accent — the highlighted word (e.g., "dreams")
  • Subheading — the paragraph below the heading
  • Primary / Secondary Button Text — the CTA button labels

After making changes, click "Save Hero".

Editing Content Sections

Below the hero, you'll see content sections (e.g., "feature_grid"). You can edit:

  • Eyebrow — section label
  • Heading — section title
  • Subheading — section description

Click "Save Section" when done.

Editing Content Blocks

Inside each section, there are individual Content Blocks (cards, text items). You can edit:

  • Title — the block heading (e.g., "Premium Ingredients")
  • Text — the block description

Click "Save Block" when done.

4. How to Edit Site Settings

  1. 1 Log in and click "Settings" in the admin sidebar.
  2. 2 Edit any of these fields:
    • Site Name — your bakery name
    • Contact Email — displayed on the website
    • Contact Phone — phone number shown to customers
    • Address — your bakery location
    • Business Hours — your opening times
    • Logo URL — path or URL to your logo image
  3. 3 Click "Save Settings".

5. How to Change Your Password

  1. 1 Log in and click "Settings" in the admin sidebar.
  2. 2 Scroll down to the "Change Password" section.
  3. 3 Enter your Current Password.
  4. 4 Enter your New Password (minimum 6 characters).
  5. 5 Enter the new password again in "Confirm New Password".
  6. 6 Click "Change Password".
  7. 7 You'll see a success message. Next time you log in, use the new password.

6. How to Manage Orders

  1. 1 Log in and click "Orders" in the admin sidebar.
  2. 2 You'll see a table with customer name, event date, cake size, delivery type, and status.
  3. 3 To change an order's status, use the dropdown in the Status column:
    • Pending → Confirmed → In Progress → Completed
    • Or set to Cancelled if needed.
  4. 4 If a customer uploaded an inspiration image, click "View Image" to see it.
💡 Tip: When a customer clicks "Order This Cake" from the gallery, their order form will automatically include a reference to the gallery image they liked. You'll see this in the Special Instructions field.
